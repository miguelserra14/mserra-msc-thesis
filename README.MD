# Vulnerability Detection via GraphCodeBERT and Structural Topologies

Author: Constança Meneses Correia

This repository contains the source code and experimental pipeline for the master's thesis dissertation: **"Enhancing Software Vulnerability Detection Using Graph Neural Networks and Large Language Models"** at the University of Coimbra.

## Overview
This framework evaluates the performance of multimodal representations for source code vulnerability detection. It integrates structural topologies—specifically Abstract Syntax Trees (AST), Control Flow Graphs (CFG), and Program Dependence Graphs (PDG) with advanced contextual embeddings generated via GraphCodeBERT. The complete pipeline covers structural graph parsing, semantic feature extraction, token-graph alignment, PyTorch Geometric dataset fusion, dimensionality reduction, data resampling (SMOTETomek), and downstream classification.

## Repository Structure

The core modules of the experimental pipeline are categorised into extraction, semantic modelling, classification, evaluation, and baseline frameworks:

### 1. Graph Extraction & Parsing
* `main.py`: The orchestrator for the graph extraction phase. Synchronises commit data with Joern parsing.
* `graph_extraction.py`: Low-level wrapper for the Joern CLI engine. Handles the parsing of raw source code into Code Property Graphs (CPGs) and exports Graphviz DOT representations.
* `version_management.py`: Handles Git repository operations, safely executing hard resets and checking out the exact vulnerable commit hashes.
* `convert_dot_to_json.py` & `update_csv_mappings.py`: Utility modules designed to validate the synchronisation between extracted structural DOT artifacts and the primary dataset records.
* `extract_mising.py`: Creates dataset subsets and verifies the presence of manual memory management features.

### 2. Semantic Representation & Fusion
* `create_embeddings.py`: The semantic feature extraction engine. Utilises `microsoft/graphcodebert-base` to ingest raw source code tokens, generating high-dimensional (768-D) contextual embeddings.
* `dataset_fusion.py`: Fuses the intermediate PyTorch embedding tensors with the structural graph edges extracted from the DOT files.
* `embedding_dataset.py`: PyTorch Geometric dataset loaders designed to ingest the serialised embedding files and structure them into iterable batches.
* `load_graphcodebert_embeddings.py`: Alternative loader to convert generated `.pt` semantic embeddings into serialised Pandas DataFrames for classical machine learning evaluation.
* `create_manifest_final.py` & `validate_embeddings.py`: Compiles the absolute dataset manifest and conducts post-generation mathematical integrity checks.

### 3. Representation Learning & Classification
* `detect_vulnerabilities.py`: The primary Deep Graph Convolutional Neural Network (DGCNN) training loop. Learns structural motifs from the embeddings using SortPooling and Adaptive Max Pooling mechanisms.
* `detect_vulnerabilities_vgg.py`: Defines the VGG convolutional architecture utilised to classify 2D projected graph features.
* `new_classifiers_svm_xgboost.py`: The advanced classical classification suite. Orchestrates Support Vector Machines (SVM) and XGBoost models, integrating Optuna for hyperparameter optimisation and SMOTETomek to mitigate severe class imbalance.
* `llm_code_classifier.py`: An experimental comparative baseline utilising zero-shot Large Language Models (GPT-4) and direct CodeBERT logistic regression to benchmark the GNN pipeline against pure sequence-based LLM architectures.

### 4. Diagnostics & Feature Analysis
* `analyze_embeddings.py`: Evaluates the structural embeddings generated by the DGCNN, projecting the feature space via PCA for latent space visualisation and establishing decision boundaries.
* `feature_correlation.py` & `create_heatmap_features.py`: Generates correlation heatmaps to analyse feature interdependencies and structural distributions across vulnerable and neutral classes.
* `utils.py`: Auxiliary utility functions for dataset sampling, balancing, and strict size filtering.

### 5. Legacy Baseline Comparison
To facilitate the baseline comparison outlined in the dissertation, the repository includes the manual feature extraction logic:
* `feature_extraction.py` & `load_datasets.py`: Extracts and loads manual statistical attributes (e.g., Code Sequence, Vertex Structure) into traditional DGL matrices.
* `graph_parsing.py`, `feature_identifier_constants.py` & `analyze_double_edges.py`: Structural validation scripts for reading raw DOT graphs and mapping specific instruction categories.

## Prerequisites & Environment Setup

### System Dependencies
The graph extraction layer requires **Joern CLI** to be installed on the host system. Ensure that `joern-parse` and `joern-export` are accessible in the system path.

### Python Environment
The implementation is compatible with Python 3.8+ environments. It is highly recommended to use a virtual environment. Install the exact dependencies using the provided requirements file:
